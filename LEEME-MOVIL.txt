NIXORA BLOX - VERSION MOVIL (PWA) Y MULTIJUGADOR

Cambios incluidos:
- Controles táctiles con joystick predeterminado y botones direccionales alternativos.
- Ajustes para cambiar el tipo y tamaño de los controles móviles.
- Botón de menú durante la partida para reanudar o salir; Esc sigue funcionando en PC.
- Sincronización de jugadores existentes al entrar a una sala, posición/rotación y nombre/rango visibles sobre los avatares.
- Servidor compartido para jugadores de PC y móvil en la misma sala.

PRUEBA LOCAL
1. Instala Node.js LTS.
2. Abre una terminal en esta carpeta.
3. Ejecuta: npm install
4. Ejecuta: npm start
5. Abre http://localhost:3000 en PC y móvil. Para probar desde un móvil en la misma Wi-Fi, usa la IP local del PC, por ejemplo http://192.168.1.20:3000 (sustituye la IP por la real).

IMPORTANTE MULTIJUGADOR POR INTERNET
Para jugar desde redes distintas, despliega esta carpeta en un hosting que admita Node.js y WebSocket, configura HTTPS/WSS en el hosting y coloca la URL pública segura en Ajustes > Servidor. No se puede habilitar multijugador global sin un servidor accesible públicamente.

INSTALAR EN EL MÓVIL
Despliega el sitio con HTTPS. Abre la URL en Chrome/Edge del móvil y elige "Instalar aplicación" o "Añadir a pantalla de inicio". Es una PWA; este paquete no contiene un APK firmado.

EXE PARA WINDOWS
El proyecto conserva Electron. En una computadora con Node.js e internet:
  npm install
  npm run dist-win
El instalador se genera en dist/. No se adjunta un EXE ya compilado en este paquete.


MEJORAS DE ESTA VERSION
- Zoom de cámara móvil con dos dedos: separarlos acerca y juntarlos aleja.
- Se conserva la animación original del personaje; no se añadieron animaciones nuevas de salto ni de agacharse.
- Chat público plegable con el botón «−» o la tecla «-» en PC. Los mensajes nuevos muestran el chat temporalmente y se oculta tras 5 segundos. Se quitaron los botones de micrófono y sonido del chat público.
- Amigos: buscar cuentas registradas en este navegador, enviar/aceptar solicitudes, bloquear, desbloquear, eliminar y abrir el apartado de mensajes privados.
- Panel de administración: lista de jugadores conectados por nombre/mundo y campo para escribir o seleccionar un usuario.

LIMITES IMPORTANTES
- Las cuentas, amistades y los mensajes privados siguen guardándose en el almacenamiento local del navegador de esta versión; no se sincronizan automáticamente entre dispositivos.
- El panel puede listar jugadores conectados al servidor; para aplicar sanciones de administrador a jugadores remotos y para tener amigos/chat privados reales entre dispositivos hace falta implementar autenticación y almacenamiento social en el servidor. El selector avisa cuando la cuenta no está disponible localmente.
- El paquete usa Three.js desde CDN, por lo que el juego 3D necesita internet para cargar esa librería.


MEJORAS DE ESTA VERSION
- Perfiles con estadísticas, biografía editable e insignias.
- Misiones diarias y logros con recompensas en Nixdollar.
- Inventario para objetos de avatar desbloqueados y objetos del Mercado.
- Studio con guardado automático local del borrador y guardado/publicación manual.
- Amigos con botón para unirse a sus mundos públicos; las salas privadas se abren con código compartido.
- Favoritos, filtros y búsqueda por nombre, descripción, hashtag o creador; incluye dos mundos nuevos.

LIMITES
Las cuentas, amistades, mensajes, progreso, inventario y misiones se guardan en el navegador (localStorage). No se sincronizan todavía entre dispositivos. El código de sala privada debe compartirse directamente con los amigos.


NIXORA STUDIO AMPLIADO (editor web propio)
- Vista 3D más grande con Toolbox a la izquierda, Explorer y Propiedades a la derecha.
- Cámara: W/A/S/D para mover el punto de vista; Q/E para bajar/subir; Shift para moverse más rápido; rueda para zoom; arrastrar la vista para orbitar.
- Insertar/seleccionar/mover/borrar/duplicar, escalar con botones, rotar en pasos de 15 grados o introducir los ángulos en Propiedades, color/material, agrupación, deshacer/rehacer, importar/exportar y Probar juego.
- Toolbox incluye un panel de Terreno para generar pradera, colinas, islas o terreno volcánico y quitar piezas generadas.
- El catálogo incluido tiene 28 mundos predeterminados con escenarios y objetivos distintos.
- Este editor se inspira en flujos comunes de herramientas 3D; no es una copia exacta ni incluye todas las funciones internas de Roblox Studio.
